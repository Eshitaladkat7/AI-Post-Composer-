# AI Post Composer

A small tool that learns your writing style from your past LinkedIn posts and
drafts new ones on a topic, length, and language you choose.

## How it works

1. **Style extraction** — your historical posts are run through an LLM to
   tag each one with its topic, language, and length, then similar tags are
   merged into a clean, consistent set.
2. **Few-shot generation** — when you ask for a new post, a couple of your
   own past posts on that topic (matching the requested length/language) are
   pulled in as style references, so the draft sounds like you.

## Project layout

```
app.py                  # Streamlit UI
src/
  config.py             # constants (length buckets, model name, paths)
  llm_client.py         # Groq LLM client setup
  style_examples.py      # loads + filters your past posts for few-shot examples
  post_composer.py       # prompt construction + generation
  data_pipeline.py       # one-time enrichment of raw posts -> processed_posts.json
data/
  raw_posts.json         # your exported posts (not included)
  processed_posts.json   # generated by data_pipeline.py
```

## Setup

1. Get a free API key from [Groq](https://console.groq.com/keys).
2. Copy `.env.example` to `.env` and fill in `GROQ_API_KEY`.
3. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
4. Drop your exported posts into `data/raw_posts.json` (list of objects with
   at least a `text` field), then run:
   ```
   python -m src.data_pipeline
   ```
5. Launch the app:
   ```
   streamlit run app.py
   ```

## Notes

- Model defaults to `llama-3.3-70b-versatile` via Groq — change it in
  `src/config.py` if you'd rather use something else.
- `data/raw_posts.json` and `data/processed_posts.json` are gitignored since
  they contain personal content.
